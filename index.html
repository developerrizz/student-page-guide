이 순서로 로그인해 주세요

수강생 페이지 열기
  1. 이름 칸에 결제자 이름을 입력하세요.
  2. 등록된 휴대폰 번호를 입력하세요.
  3. 들어가기를 누르세요.

    로그인이 완료되면 수강생 홈 화면이 열립니다.

결제자 이름이 본인 이름과 달라 본인 이름으로 이용하고 싶다면, 운영팀에 이름 변경을 요청해 주세요.

로그인이 안 된다면

결제자 이름과 휴대폰 번호를 다시 확인해 주세요. 계속 입장되지 않으면 운영팀에 등록 정보를 확인해 주세요.

이미 로그인되어 있다면 로그인 화면 없이 홈이 열릴 수 있습니다.

홈에서 먼저 확인해 주세요

  1. 라이브 일정을 확인하세요.

    일정을 누르면 전체 달력을 볼 수 있습니다.

  2. 이번 주 과제와 마감 시간을 확인하세요.

    항목을 누르면 내 제출에서 코치님의 의견을 볼 수 있습니다.

  4. 새로운 공지를 확인하세요.

    공지를 누르면 운영팀과 코치님의 안내를 읽을 수 있습니다.

아래쪽의 내 과제 기록에는 주차별 과제와 제출·피드백 기록이 모여 있습니다. 질문 답변 알림을 누르면 질문 화면으로 이동합니다.

2. 과제 파일 제출하기파일 선택 · 메모 · 제출하기

이미 제출한 과제에 파일을 추가하려면 먼저 파일 더 올리기를 누르세요. 파일 선택 칸이 보이면 아래 순서대로 진행합니다.

  1. 파일 선택 칸을 눌러 제출할 파일을 고르세요.

    여러 개를 선택할 수 있으며, 화면 안내는 파일 하나당 2GB입니다.

  2. 전달할 설명이 있으면 메모에 적으세요.

    메모에는 2,000자 기준의 글자 수가 표시됩니다.

  3. 제출하기를 누르세요.

    전송이 끝날 때까지 페이지를 닫지 말고 기다려주세요.

마지막으로 내 제출에서 확인하세요

파일을 고르는 것만으로 끝나지 않습니다. 제출하기까지 누른 뒤 내 제출에서 과제 제목과 파일 이름을 확인해 주세요.
